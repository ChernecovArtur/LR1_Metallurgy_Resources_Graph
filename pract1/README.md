# Практика 1. Поиск в Common Crawl

Чернецов А. А., АСУ4-25-1м

Сделал консольное приложение для поиска страниц в Common Crawl. Для поиска используется CDX-индекс, а содержимое страниц загружается из WARC только при необходимости через Range-запрос.

Программа принимает ключевые слова, домен и ограничение числа результатов. Также можно искать слова в тексте страниц и выводить распределение результатов по доменам и месяцам архивации.

Пример запуска:

python pract1.py pstu --domain pstu.ru --text перм пнипу --stats

В результате была проверена страница https://pstu.ru/about/. В её тексте найдены оба слова.

URL: https://pstu.ru/about/
Дата архивации: 2025-07-19
Заголовок: Университет
Домен: pstu.ru
Месяц архивации: 2025-07

Во время выполнения практики CDX периодически возвращал ошибки 503, 504 и разрывал соединение. 
Поэтому для проверки программы использовалась сохранённая запись CDX. 
Загрузка WARC, извлечение текста, поиск слов и вывод статистики выполнялись программой.

Из-за недоступности CDX остальные исследовательские запросы по кафедре ИТАС, МГУ, МФТИ и Пастернаку не выполнялись на полном наборе страниц.
